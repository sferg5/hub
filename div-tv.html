HOW THE HACK WORKS

The "screen" is a CSS grid containing one <div> per pixel. Each channel is a tiny software renderer that writes 8-bit palette indices into a plain Uint8Array framebuffer — exactly like a 1990s demo effect. Thirty times a second, the frame is "scanned out" by diffing the new framebuffer against the previous one and setting style.backgroundColor only on the divs that changed. That diff is the whole trick: repainting all ~3,600 divs every frame would choke layout, but touching only the deltas keeps the browser comfortable even at 11k+ divs.

CH3 is the fun one — a genuine 3D renderer (rotation matrices, perspective projection, back-face culling, flat shading, triangle rasterization with edge functions) whose render target happens to be the DOM. Tick "expose the divs" to add a 1px grid gap and see the individual elements. Open devtools and inspect the screen if you don't believe it.
